# Opponent Scout Hub — 開発・公開ガイド

このリポジトリには2つのフォルダがあります。役割が違うので、混同しないようご注意ください。

- **`app/`（このフォルダ）** — アプリの「元データ」（ソースコード）です。表示内容やデータを直すときは、必ずここを編集します。
- **`../site/`** — `app/` から自動生成される、**サーバーにそのままアップロードする最終ファイル一式**です。HTML・CSS・JS・画像・フォントがすべて含まれています。**このフォルダの中身は手で編集しないでください**（次にビルドすると上書きされて消えます）。

## サーバーへの公開方法

`../site/` フォルダの中身（`index.html` や `assets/` フォルダなど）を、そのままレンタルサーバー等にアップロードしてください。サブフォルダ（例: `example.com/scouthub/`）に置いても、ドメイン直下に置いても、どちらでも正しく表示されるように作ってあります。外部サイトへの通信（Google Fonts・国旗画像のCDNなど）は一切行わないため、アップロード先のサーバーとインターネットに正常に繋がっていれば、それ以外の設定は不要です。

## 内容を修正したいとき

1. `app/src/` 内の該当ファイルを編集します（下記「フォルダ構成」を参照）。
2. ターミナルで以下を実行します。

   ```
   cd app
   npm install   # 初回のみ
   npm run build
   ```

3. `../site/` フォルダの中身が自動的に更新されます。その中身を再度サーバーにアップロードしてください。

## フォルダ構成（`app/src/`）

- `data/` — 対戦国一覧、カテゴリー、監督名、信頼度ティアなど、画面に出てくる基礎データ
- `lib/` — 上記データから試合結果・スケジュールなどを生成するロジック
- `state/` — 画面遷移やフィルタなど、アプリの状態管理
- `components/screens/` — 画面ごとの見た目（ホーム・国別詳細・監督プロファイル・動画要約・情報源管理・更新フィード・レポート出力）
- `components/shell/` — サイドバー・ヘッダー
- `components/primitives/` — 国旗表示・タグ・バッジなど共通部品
- `styles/` — 配色・余白などデザインの基本ルール（`design-system.css`）と、紺色アクセントへの上書き（`accent-override.css`）、自前ホスティングしているフォント定義（`fonts.css`）
- `assets/flags/` — 対戦国の国旗画像（SVG、外部サイトを使わずアプリに同梱）
- `assets/fonts/` — 見出し用フォント Barlow / Barlow Condensed（同じく同梱）

## 動作確認（任意）

サーバーにアップロードする前に手元で見た目を確認したい場合は、以下でプレビューできます。

```
cd app
npm run dev
```

表示されたURLをブラウザで開くと、公開前の状態を確認できます（この方法はあくまで確認用で、公開には使いません。公開には `../site/` の中身をアップロードしてください）。
